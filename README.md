# 人生ロードマップ

人生目標を立て、そのロードマップを作製できるWebアプリケーション。

## 機能

- **ブロック表現**: 小学校・中学校・高校・大学などの学校ライフステージをブロックで表現
- **3行レイアウト**: メインライン（学校・キャリア）、課外活動（部活・サークル）、その他（インターンシップ等）の3行で整理
- **10年ごとの区切り**: 背景に10年ごとの点線を表示し、時間軸を明確に
- **人生の目標**: 右端に人生の目標を設定
- **自由なカスタマイズ**: ブロックの追加・編集・削除が可能
- **データ永続化**: localStorageに自動保存

## 使い方

1. 「＋ ブロック追加」ボタンで新しいブロックを追加
2. ブロックをクリックして編集・削除
3. キャンバスをダブルクリックしてその位置にブロックを追加
4. 「🎯 目標を設定」ボタンで人生の目標を設定

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
